# 木作封面工坊

作者：彭杰 · 联系微信：305519722。

静态网页版支持封面编辑、逐图配文、批量PNG/ZIP、长图和小红书图文发布包。识图在访问者浏览器内运行，首次需从Hugging Face下载约154MB模型；模型与运行组件需要联网，照片不发送到模型供应商。低可信建议需人工确认。小红书账号与自动发文尚未连接。

运行组件：@huggingface/transformers 4.3.1（Apache-2.0），ONNX Runtime（MIT）；模型Xenova/clip-vit-base-patch32（CLIP，MIT）。模型许可与说明以供应方页面为准：https://huggingface.co/Xenova/clip-vit-base-patch32 。
